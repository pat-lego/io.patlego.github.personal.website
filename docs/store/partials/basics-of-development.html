🎒 What to Bring

A laptop (Windows or Mac) with its power cable, and Node, Python, or Java already installed from Intro to Dev (whichever language you're continuing with).

Why does this matter?

Typing one line into a shell is great for learning an idea, but it disappears the moment you close the window. Real software lives in files, is organized into functions and objects, and reacts to input. This course is about making that jump — not by explaining it in the abstract, but by building one real, playable thing from the ground up.

Curriculum

Module 0

From Shell to Real Files

Writing, saving, and running your first real .js, .py, or .java file.

Module 1

Lists & Arrays: Representing a Board

Using a list of lists to represent an 8x8 checkers board in code.

Module 2

Nested Loops: Printing the Board

Walking through every row and column to print the board to the screen.

Module 3

Functions & Program Structure

Breaking the program into reusable pieces like printBoard and movePiece.

Module 4

Conditionals for Game Rules

Enforcing whose turn it is and whether a move is actually legal.

Module 5

Objects & Classes

Grouping data together with a Piece class that tracks color and king status.

Module 6

Reading Player Input

Prompting a player for a move and turning their answer into board coordinates.

Capstone

Building the Checkers Game

Assembling every module above, step by step, into a working two-player Checkers game you can actually play in your terminal.

What's next?

Once your Checkers game works, you'll have a real foundation to build almost anything: multi-jumps, an AI opponent, or a totally different game using the same board-and-rules pattern.
